# AGENTS.md - Permanent Operating Manual for AI Agents

## Overview
This document serves as the permanent operating manual for all AI agents working on **Aqib Abdul Ghaffar's Premium Portfolio**. Every agent MUST follow these guidelines strictly to ensure consistency, quality, performance, and adherence to design specifications.

## 🚨 Essential Directives
1. **Source of Truth**: The 6-page Portfolio Reference PDF is the visual and structural primary source of truth.
2. **Memory System**: Always check and update `AGENTS.md`, `README.md`, `TASK.md`, `DECISIONS.md`, and `CHANGELOG.md` during development cycles.
3. **No Placeholders**: Never use placeholder text or low-quality placeholder images. Generate high-fidelity assets or build dynamic canvas/svg graphics where needed.
4. **Design Quality**: Liquid glass, glassmorphism gradients, glow effects, smooth Framer Motion / GSAP animations, perfect typography (Inter / Outfit / Plus Jakarta Sans).
5. **Lint & Types**: Zero TypeScript errors, zero ESLint warnings, fully responsive across mobile, tablet, desktop, and ultra-wide.

## Workflow Rules
- Step 1: Read memory files (`AGENTS.md`, `README.md`, `TASK.md`, `DECISIONS.md`, `CHANGELOG.md`).
- Step 2: Study the PDF screenshot for the relevant section.
- Step 3: Implement components in modular TypeScript files.
- Step 4: Run typechecks and linting.
- Step 5: Update `README.md`, `TASK.md`, `DECISIONS.md`, `CHANGELOG.md`.
- Step 6: Present completed work and request approval for next phase.
